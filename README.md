# Movie Storyboard Helper

제품 이미지와 상품 URL을 넣으면 **영상 시작/끝 프레임 프롬프트**와 **장면별 스토리보드(한글/영문)** 를 만들어 주는 크롬 확장 프로그램입니다. Google Flow(Veo) 같은 "시작 프레임 + 끝 프레임 → 영상" 워크플로에 붙여넣어 쓰도록 설계했습니다.

## 기능

- 상품 URL의 제목·설명·본문 일부를 읽어 제품 정보를 파악 (이미지를 올리지 않으면 대표 이미지 `og:image` 자동 사용)
- 제품/모델 이미지 최대 4장 (끌어다 놓기, 선택, 붙여넣기)
- 장면 수(2~6), 클립 길이(4/6/8초), 화면 비율(16:9 / 9:16 / 1:1), 분위기 선택
- 결과: 제품 요약 · 콘셉트 · 시작 프레임 · 끝 프레임 · 장면별 연출/카메라/영상 프롬프트 (한글 + 영문, 항목별 복사 버튼)
- 시작/끝 프레임 **이미지 생성** 버튼 (Gemini 이미지 모델, 클릭할 때만 과금)
- 전체 복사, `.md` / `.json` 저장

## 설치 (개발자 모드)

1. 크롬에서 `chrome://extensions` 를 엽니다.
2. 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`movie_storiboard`)를 선택합니다.
4. 툴바의 확장 아이콘을 누르면 작업 화면이 새 탭으로 열립니다.

## 처음 설정

화면 오른쪽 위 **⚙ 설정**에서 입력합니다.

| 항목 | 설명 |
|---|---|
| AI 제공자 | Google Gemini 또는 Anthropic Claude |
| API 키 | 선택한 제공자의 키 (이 브라우저의 `chrome.storage.local`에만 저장) |
| 모델명 | Gemini 기본 `gemini-2.5-flash`, Claude 예 `claude-sonnet-5-5` |
| 이미지 모델명 | 기본 `gemini-3.1-flash-image` |
| 이미지용 Gemini 키 | 제공자를 Claude로 쓸 때만 필요 (프레임 이미지 생성은 Gemini 전용) |

> API 키는 코드나 저장소에 포함되지 않습니다. 공용 PC에서는 사용 후 설정에서 키를 지우세요.

## 사용 순서

1. 상품 URL과 이미지를 넣고 요청사항을 적습니다.
2. **스토리보드 만들기**를 누릅니다.
3. 영어(English) 프롬프트를 Flow 등에 붙여넣습니다. 한글은 확인용입니다.
4. 필요하면 시작/끝 프레임 **이미지 생성**으로 프레임 이미지를 만들고 저장해 Flow의 시작/끝 프레임으로 올립니다.

## 비용과 주의

- 스토리보드 텍스트 생성은 호출 1회당 소액입니다. 프레임 이미지 생성은 호출할 때마다 Gemini 이미지 요금이 부과됩니다(모델·해상도별 요금은 [Google 가격표](https://ai.google.dev/pricing) 확인).
- 제품 외형은 참고 이미지 기준으로 "동일하게 유지"하도록 요청하지만, AI 생성 특성상 로고 글자나 세부가 달라질 수 있으니 결과를 꼭 확인하세요.
- 실존 인물·연예인을 닮게 만드는 용도로 사용하지 마세요. 타 브랜드 제품은 연습용에 한정하세요.
- Flow 웹 화면에 자동 입력하는 기능은 없습니다. Flow의 크레딧은 외부 API로 사용할 수 없어서 복사/붙여넣기 방식으로 연동합니다.

## 파일 구성

```
manifest.json   확장 설정 (Manifest V3)
background.js   아이콘 클릭 시 작업 화면 열기
app.html/css/js 작업 화면 (입력·AI 호출·결과 표시·이미지 생성)
icons/          확장 아이콘
```
